ANKUSH & AAYUSHI WEDDING INVITATION - VERCEL PROJECT

Files:
- index.html: page structure
- style.css: all styling
- script.js: interactions and page behavior
- assets/: extracted images used by the page
- vercel.json: simple Vercel URL configuration

DEPLOY:
1. Extract this ZIP.
2. Open https://vercel.com and sign in.
3. Choose Add New -> Project -> Deploy from folder (or import a Git repository).
4. Upload/import the extracted project folder. Keep index.html in the root.
5. Framework Preset: Other. Build Command: leave blank. Output Directory: ./
6. Deploy.

Do not upload only index.html. Upload the whole folder so CSS, JS and images remain connected.
